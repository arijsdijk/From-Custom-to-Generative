# From Custom to Generative - Closing the Gaps in Model-Driven Apps

Practical material for extending model-driven apps with custom and generative
pages. The presentation follows the journey from building a model-driven app to
adding flexible page experiences, generating pages with AI, and opening them
in context from forms and grids. It also covers display options, development
approaches, availability considerations, and ways to keep the experience
consistent with the host app.

## Repository contents

| Item | Description |
| --- | --- |
| [Slides](./slides/README.md) | The presentation, covering model-driven apps, custom pages, generative pages, AI-assisted development, page display options, and practical implementation tips.  |
| [Instruction](./instruction/README.md) | Guidance and JavaScript examples for opening custom or generative pages from model-driven app forms and grids, including how to pass table and record context. |
| [User interface](./user-interface/README.md) | A visual baseline and component guidance for pages that fit naturally into a model-driven app. Includes reusable UI tokens, accessibility and responsive-design recommendations, and a prompt for AI-assisted implementation. |

## Getting started

Start with the [slides](./slides/README.md) for the overall concepts and examples.
Use the [instruction guide](./instruction/README.md) when wiring page navigation
to a form or grid command bar, and consult the [user-interface guidance](./user-interface/README.md)
when designing a page to match its host app.
